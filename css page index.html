Demo 2 — Hover Transitions

CSS transition interpolates between property values. Hover the card to see background colour, border, transform, and a pseudo-element animate simultaneously.

Hover me

Smooth Transitions

Four properties change at once: background, border-color, translateY, and the ::before scaleX — all driven by a single hover rule and transition shorthand.

.card { transition: background 0.35s ease, border-color 0.35s ease, transform 0.25s ease; } .card::before { /* top accent bar */ transform: scaleX(0); transition: transform 0.35s ease; } .card:hover::before { transform: scaleX(1); }
