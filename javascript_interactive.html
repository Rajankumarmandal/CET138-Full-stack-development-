Demo 03 Accordion — CSS + JS toggling

Clicking a trigger adds/removes a CSS class. CSS max-height transition handles the animation — JS only manages state. Aria attributes keep it accessible.

An event listener is a function called when a specific event fires on an element — such as a click, keypress, or scroll. Attach one with element.addEventListener('event', callback).
The Document Object Model (DOM) is a tree-like representation of an HTML page. JavaScript can read or modify any element, attribute, or text through the DOM API using methods like getElementById and querySelector.
classList exposes methods to add, remove, or toggle CSS class names on an element. toggle('open') adds the class if absent and removes it if present — ideal for show/hide patterns like this accordion.
A closure is a function that retains access to variables from its outer scope even after that scope has returned. This lets you create private state — for example, each accordion item's handler "remembers" which panel belongs to it.
// Toggle panel open/closed function setupAccordion() { triggers.forEach(btn => { btn.addEventListener('click', () => { const panel = btn.nextElementSibling; const open = btn.getAttribute('aria-expanded') === 'true'; btn.setAttribute('aria-expanded', !open); panel.classList.toggle('open', !open); }); }); }
